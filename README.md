# Bhakti Wagh Portfolio

Vite + React + TypeScript + Tailwind CSS (same stack as SenseHack).

    npm install
    npm run dev       # local dev server
    npm run build     # production build to dist/

Deploy: push to GitHub and import the repo in Vercel (framework preset: Vite).

Edit your content in `src/data.ts` and `src/components/Sections.tsx`.
Put images in `public/`.
